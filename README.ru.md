# Export HyperLynx

Расширение для EasyEDA Pro — экспортирует проекты печатных плат (PCB) в формат HyperLynx (.hyp) для анализа целостности сигналов.

![alt text](images/image1.png)

## Возможности

- Экспорт текущего PCB-документа в файл `.hyp` формата HyperLynx 2.14
- Включает:
  - Контур платы (`BOARD`)
  - Стек слоев (`STACKUP`) с медными и диэлектрическими слоями
  - Список устройств (`DEVICES`)
  - Определения стеков пятачков/переходных отверстий (`PADSTACK`)
  - Данные цепей (`NET`): контакты (`PIN`), переходные отверстия (`VIA`), дорожки (`SEG`), дуги (`ARC`) и полигоны заливки (`POLYGON`)
- Автоматическая обработка неподключенных объектов, чтобы не терялись данные
- Автоматическое преобразование координат из mil в дюймы в соответствии с системой координат HyperLynx
- Экспорт в один клик через верхнее меню

## Использование

1. Откройте PCB-документ в EasyEDA Pro
2. Нажмите в верхнем меню **Export HyperLynx → Export HyperLynx (.hyp)...**
3. Выберите место сохранения в диалоговом окне, чтобы сгенерировать файл `.hyp`

## Формат выходного файла

Сгенерированный файл `.hyp` соответствует спецификации HyperLynx 2.14 ASCII и содержит следующие секции:

| Секция | Содержание |
|--------|------------|
| `{VERSION}` | Версия формата 2.14 |
| `{UNITS}` | Английские единицы длины (дюймы) |
| `{BOARD}` | Контур платы |
| `{STACKUP}` | Стек медных и диэлектрических слоев |
| `{DEVICES}` | Обозначения устройств и слои |
| `{PADSTACK}` | Определения стеков пятачков/переходных отверстий |
| `{NET}` | Объекты цепей (PIN / VIA / SEG / ARC / POLYGON) |

Подробнее о формате см. [docs/hyperlynx-file-format.md](./docs/hyperlynx-file-format.md).

## Совместимость и ограничения

- Требуется EasyEDA Pro 3.2.0 или новее
- Перед экспортом убедитесь, что PCB-документ сохранен и содержит необходимую информацию о медных слоях
- Дуги в сложных контурах платы аппроксимируются отрезками
- Неподдерживаемые формы пятачков аппроксимируются эллипсами/окружностями
- Вырезы и слоты внутри платы могут не экспортироваться
- Рекомендуется проверить ключевые размеры после импорта в PADS или HyperLynx

## Структура проекта (для разработчиков)

```text
src/
├── index.ts    # Точка входа расширения и команда экспорта
├── collect.ts  # Сбор данных PCB
├── generate.ts # Генерация файла .hyp
├── types.ts    # Определения типов
├── utils.ts    # Вспомогательные функции
└── writers/    # Реализация записи секций
    ├── board.ts
    ├── stackup.ts
    ├── devices.ts
    ├── padstacks.ts
    └── nets.ts
```

## Разработка

```shell
npm install
npm run build
```

Пакет расширения генерируется по пути:

```text
./build/dist/export-hyperlynx_v1.0.0.eext
```

Установите полученный `.eext` пакет в EasyEDA Pro.
